# OZE

**OZE (one-zero-eight)** is an online portfolio showcasing a system developed for **IT-108**.

The portfolio presents **Hum-i (Humay)**, a web and mobile-based system designed for agricultural data acquisition and analysis, particularly for rice cultivation in Western Visayas.

## About the System

**Hum-i (Humay)** is a multi-stage data acquisition and analysis system designed to help collect, manage, synchronize, and analyze agricultural data.

The system supports:

* Mobile-based data collection
* Web-based data management and visualization
* Centralized database storage
* Offline-first data collection and synchronization
* Data validation and standardized input
* Agricultural and yield analytics
* Farmer and field record management

## Portfolio

This website serves as an online portfolio for the project, showcasing the system's:

* Rationale
* Objectives & Queries
* Database Architecture
* Entity Relationship Diagram
* DB Fiddle
